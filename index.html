Tu privacidad

Seguridad

Controles de acceso y límites de esta versión.

Bóveda cifrada

Los datos se cifran con AES-GCM y una clave derivada de tu contraseña mediante PBKDF2. La contraseña no se guarda.

ACTIVA

Bloqueo por inactividad

La bóveda se bloquea automáticamente después de 5 minutos sin actividad. También puedes bloquearla al salir del dispositivo.

Almacenamiento local

Los datos cifrados permanecen en el navegador de este dispositivo. Borrar los datos del navegador elimina la bóveda.

SOLO ESTE EQUIPO
Importante: esta base no incluye sincronización, recuperación de contraseña, autenticación del sistema operativo ni protección frente a malware o a alguien que ya pueda usar tu sesión desbloqueada. Para publicar la aplicación, se necesita una revisión de seguridad y un backend autenticado.
